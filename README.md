# BASE ARCHITECT

A 3D, 44 × 44 grid designer for planning Clash of Clans village layouts. Paint, erase and recolour 1,936 tiles on a WebGL board you can orbit, pan and zoom. Built with React, Three.js and React Three Fiber.

## Run it

Requires Node 18+.

```bash
npm install
npm run dev
npm run build
npm run preview
npm test
```

See `src/core`, `src/state`, `src/scene`, and `src/ui` for the implementation. Logic tests cover grid operations, undo/redo, import/export, and storage.
